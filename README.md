# Cem por Dia

Aprenda inglês com 100 frases novas por dia. Cada frase vira uma cena na tela; você ouve, repete em voz alta e derruba drones falando a frase.

- Site: abra `index.html` (ou o endereço do GitHub Pages) no Google Chrome ou Edge e permita o microfone.
- Plano: 180 dias, do A1 ao C1. Mês 1 (dias 1 a 30) pronto.
- `audio/dNNN.js`: vozes em inglês de cada dia (Kokoro TTS).
- `fonte/`: frases (`content.py`, `dias_*.py`), plano (`curriculo.py`), modelo da página (`site.html`) e scripts (`gen_audio.py`, `build.py`).
